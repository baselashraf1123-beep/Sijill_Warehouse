# نظام سِجِلّ المخازن (Sijill Warehouse) — أرشيف مستندات المخازن لسطح المكتب

تطبيق سطح مكتب محلي متكامل لأرشفة صور مستندات المخازن وسلاسل الإمداد بذكاء وتنظيم عالٍ، يجمع بين قاعدة بيانات **SQLite FTS5** للبحث الفوري، وبصمة **SHA-256** لمنع تكرار الصور، ومحرك **Pillow** لمعالجة الصور وتصدير ملفات **PDF** و**CSV**.

## تطوير وبرمجة
- **المطور:** م. باسل أشرف
- **للتواصل:** `01014543845`

## المتطلبات
- Python 3.10+
- مكتبة `Pillow` (`pip install pillow`)

## تشغيل الاختبارات
```bash
python3 -m unittest test_sijill.py -v
```
